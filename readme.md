# Before you can run, you learn how to walk.

Its time to write some C by hand. No model help. Just the *man pages* and effort.

## Tasks

1) Write a helloworld using C17 that accepts one argument as a list of strings: "all","the", and "things".

The main function must call a defined function "char** parse_args(char** list)". The *list* parameter is a static list of strings.

The parse_args(...) function must handle a max string length of 25 characters for each item in the list. It must also handle empty strngs.


## Submitting

Once this is done, submit your code as a pull request for review.
